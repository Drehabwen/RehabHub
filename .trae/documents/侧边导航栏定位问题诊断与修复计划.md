### 问题现象详细描述

**1. 当前页面布局结构**
*   **整体架构**: 使用 Flexbox 布局。
*   **容器 (`LayoutContainer`)**: `flex-col`, `min-h-screen`。
*   **主内容区 (`Main`)**:
    *   在移动端 (`md:hidden`生效时): `flex-col` (垂直排列)。
    *   在桌面端: `flex-row` (水平排列)。
    *   **子元素顺序**: `Navigation` (包含 `Sidebar`) -> `Content` (页面内容) -> `BottomNavigation`。

**2. 导航栏的具体样式和定位方式**
*   **组件**: `Navigation` 组件内部使用了 `Sidebar` 组件。
*   **定位冲突 (核心原因)**:
    *   **意图**: `Navigation` 组件试图通过 Tailwind 类名 `fixed inset-y-0 right-0` 将侧边栏设置为**固定定位 (Fixed)**，使其脱离文档流悬浮在页面上。
    *   **现状**: `Sidebar` 组件定义中（`Layout.tsx` 第 135 行）包含了**内联样式 (Inline Style)** `position: 'relative'`。
    *   **结果**: 根据 CSS 优先级规则，**内联样式 > CSS 类名**。因此，侧边栏实际上是 **相对定位 (Relative)**。
*   **层级 (z-index)**:
    *   `Sidebar` 内联样式设置了 `zIndex: 2`。
    *   `Navigation` 试图设置 `z-50`，但同样被内联样式覆盖。

**3. 问题出现的具体场景**
*   **移动端 (Mobile)**: 由于 `Main` 容器是 `flex-col`，且 `Navigation` 是第一个子元素。因为它是 `relative` (相对定位)，即使通过 `translate-x-full` 在视觉上移出了屏幕，它**仍然在文档流中占据原有的空间**。这导致页面顶部出现了一大块空白区域（即侧边栏原本的高度），将实际内容挤到了下方。
*   **桌面端 (Desktop)**: 同样占据文档流空间，可能导致左侧出现空白或布局错位。

**4. 根源分析**
`Sidebar` 组件的内联样式 `position: 'relative'` 强制覆盖了 `Navigation` 传入的 `fixed` 样式，导致侧边栏无法脱离文档流。
